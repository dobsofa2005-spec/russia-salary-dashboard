# 📈 Зарплаты в России: интерактивная аналитика, 2000–2023

Интерактивное **Streamlit-приложение** для исследования среднемесячных начисленных зарплат по видам экономической деятельности в России. Учебный бонусный проект на основе исследования зарплат, инфляции и безработицы.

> **🌐 Публичное приложение: https://russia-salary-dashboard-muedvlyrezc6rdfqefzahz.streamlit.app
>
> **👤 Автор: Софья Шастина.*

## Что умеет приложение

- Сравнивает номинальные зарплаты за **2000–2023** по **трём отраслям**: добыча полезных ископаемых, обрабатывающие производства и образование.
- Пересчитывает зарплаты в приближённые **рубли конца 2023 года** по годовой инфляции; показывает рост покупательной способности относительно выбранного года.
- Сравнивает **номинальный рост, инфляцию и реальный рост** по годам и отображает тепловую карту годовых изменений.
- Исследует связь **реального роста зарплат с изменением безработицы**: диаграмма рассеяния, линия тренда и корреляция Пирсона (с исключением перехода на ОКВЭД2 в 2017 г.).
- Предлагает фильтры по годам и отраслям, переключатели режимов, сброс настроек и выгрузку данных в CSV.

## Описание датасета

В локальном файле [`data/salaries_2000_2023.csv`](data/salaries_2000_2023.csv) — 24 годовых наблюдения (2000–2023 гг.) и шесть столбцов:

| Столбец | Описание |
|---|---|
| `year` | Год |
| `mining` | Номинальная среднемесячная начисленная зарплата, добыча, ₽ |
| `manufacturing` | Аналогично, обрабатывающие производства, ₽ |
| `education` | Аналогично, образование, ₽ |
| `inflation_pct` | Инфляция за год, %, декабрь к декабрю |
| `unemployment_pct` | Уровень безработицы, %, годовой показатель |

Это начисленная зарплата, **до вычета НДФЛ**, а не медианная зарплата. Рублёвые значения округлены до целых рублей.

### Источники

1. [Росстат — «Рынок труда, занятость и заработная плата»](https://rosstat.gov.ru/labor_market_employment_salaries) — официальные таблицы зарплат работников организаций по видам деятельности.
2. [Таблица инфляции в России](https://xn----ctbjnaatncev9av3a8f8b.xn--p1ai/таблицы-инфляции) — годовая инфляция (декабрь к декабрю).
3. [Справочные показатели безработицы](https://www.russiaeconomy.org/ru/tools/indicators/) (по данным российской статистики), [методика Росстата](https://rosstat.gov.ru/labour_force).
4. Для переноса отраслевых рядов использованы [машиночитаемые таблицы, воспроизводящие Росстат за 2000–2016](https://github.com/Olga57/Start-DS/blob/main/salary_1.csv) и [2017–2023](https://github.com/Olga57/Start-DS/blob/main/salary_2.csv).

Изначальный проект: «Анализ заработных плат в России, 2000–2023». Все значения данных уже включены в репозиторий; сторонние API и секреты не нужны.

### Методика и ограничения

При номинальной зарплате `W_t` и инфляции `pi_t` (%) годовой приблизительный реальный темп изменения вычисляется как:

```text
real_growth_t = (W_t / W_(t−1) / (1 + pi_t/100) - 1) * 100%
```

Пересчёт зарплат в **условные рубли конца 2023 года**: `W_t * P_2023 / P_t`, где `P_t` — накопленный индекс цен, `P_2000 = 1`, а множитель инфляции 2000 года для базы не применяется.

**Важно:** инфляция декабрь/декабрь — лишь приближённый дефлятор *среднегодовой* зарплаты. Полученные оценки **не равны официальному индексу реальной заработной платы**. Отраслевые ряды могут иметь методологический разрыв **2016→2017** при переходе на ОКВЭД2. Корреляция с безработицей не доказывает причинности.

## Запуск локально

Рекомендуется Python **3.12** (также поддерживается Python 3.13). При создании приложения в Streamlit Cloud версия Python выбирается в **Advanced settings**; рекомендуем установить 3.12.

```bash
python -m venv .venv
# macOS/Linux:
source .venv/bin/activate
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

В браузере откроется `http://localhost:8501`.

Для проверки вычислений:

```bash
pip install pytest
python -m pytest -q
```
